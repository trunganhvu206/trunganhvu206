## What you'll find here, once it's here

Every project I publish will follow the same shape, because that's how I want to be judged:

| Section | What it answers |
| :--- | :--- |
| **Question** | What decision the analysis informs, in plain language |
| **Data** | Source, size, licence, and what made it awkward |
| **Approach** | Cleaning, features, models compared, validation scheme |
| **Results** | The metric, measured against an honest baseline |
| **Takeaways** | What worked, what didn't, what the model still can't do |
| **Reproduce** | Clone, install, run — top to bottom, no missing steps |
